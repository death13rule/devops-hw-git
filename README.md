# devops-hw-git

Файл `.gitignore` описывает, какие файлы и директории не должны попадать в репозиторий при работе с Terraform. Ниже расшифрованы используемые в нём конструкции языка gitignore.

### Спецсимволы:

- **Звёздочка `*`** — заменяет любое количество любых символов (кроме `/`). Например, правило `*.tfstate` означает: игнорировать все файлы, имя которых заканчивается на `.tfstate` (независимо от того, что находится перед точкой).

- **Слэш `/` в начале** — указывает, что правило применяется только к файлам и папкам в корне репозитория. Например, `/.terraform/` игнорирует только корневую папку `.terraform`.

- **Слэш `/` в конце** — явно указывает, что правило относится к директории. Например, `.terraform/` — игнорируется директория с таким именем на любом уровне вложенности.

- **Восклицательный знак `!` в начале** — отменяет ранее заданное правило игнорирования (инвертирует его). Это позволяет включить файл, который ранее был исключён.

### Расшифровка правил по именам файлов и директорий:

- `.terraform/` — будут игнорироваться директории с именем `.terraform` на любом уровне вложенности.

- `*.tfstate` — будут игнорироваться все файлы, содержащие в имени буквосочетание `.tfstate` в конце имени файла.

- `*.tfstate.*` — будут игнорироваться все файлы, содержащие в имени буквосочетание `.tfstate.` (после точки могут идти любые символы).

- `crash.log` — будет игнорироваться файл с именем `crash.log` в любой директории.

- `crash.*.log` — будут игнорироваться все файлы, в имени которых есть буквосочетание `crash.`, затем любые символы, затем `.log`.

- `*.tfvars` — будут игнорироваться все файлы, заканчивающиеся на `.tfvars`.

- `*.tfvars.json` — будут игнорироваться все файлы, заканчивающиеся на `.tfvars.json`.

- `override.tf` — будет игнорироваться файл с именем `override.tf` в любой директории.

- `*_override.tf` — будут игнорироваться все файлы, заканчивающиеся на `_override.tf`.

- `*_override.tf.json` — будут игнорироваться все файлы, заканчивающиеся на `_override.tf.json`.

- `.terraform.tfstate.lock.info` — будет игнорироваться файл с именем `.terraform.tfstate.lock.info`.

- `.terraformrc` — будет игнорироваться файл `.terraformrc` в любой директории.

- `terraform.rc` — будет игнорироваться файл `terraform.rc` в любой директории.
